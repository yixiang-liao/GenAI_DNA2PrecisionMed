多重檢定校正Multiple Testing Correction (FDR)

Concept ID: multiple-testing · Last Updated: 2026-11-23

初學者Beginner L1

一次檢定兩萬個基因，就算全都沒差異，用 p < 0.05 也會「碰巧」找到約 1,000 個。所以要把門檻變嚴格。

Test 20,000 genes at p < 0.05 and about 1,000 will look significant by chance even if none differ. So the threshold must be tightened.

進階Advanced L2

Bonferroni 把顯著門檻除以獨立檢定數；GWAS 的 5 × 10⁻⁸ 即約為 0.05 / 10⁶。差異表現分析常用 Benjamini–Hochberg 程序控制 false discovery rate，例如 DESeq2 對通過 independent filtering 的基因校正 Wald 檢定 P 值。

Bonferroni divides the threshold by the number of independent tests; GWAS's 5 × 10⁻⁸ ≈ 0.05 / 10⁶. Differential expression usually controls the false discovery rate with Benjamini–Hochberg, e.g. DESeq2 adjusts Wald-test P values for genes passing independent filtering.

例子Examples

  • （示意）20,000 個基因 × 0.05 = 預期 1,000 個假陽性；Bonferroni 門檻 = 0.05 / 20,000 = 2.5 × 10⁻⁶。(Illustrative) 20,000 genes × 0.05 = 1,000 expected false positives; Bonferroni threshold = 0.05 / 20,000 = 2.5 × 10⁻⁶.
