PGS CatalogPolygenic Score Catalog (PGS)

Concept ID: pgs-catalog · Last Updated: 2026-11-13

初學者Beginner

PGS Catalog 是公開的「分數食譜庫」：每個已發表的 PRS 用了哪些 SNP、哪個 allele、多少權重，都可以下載。

The PGS Catalog is a public "recipe library" of published scores: which SNPs, which alleles and what weights, all downloadable.

進階Advanced

提供評分檔（variant、effect allele、weight）與標準化 metadata（開發族群、評估族群、效能指標），支援再現與獨立評估。選用分數時應檢查其開發與評估族群是否符合目標族群。

It provides scoring files (variant, effect allele, weight) and standardized metadata (development and evaluation ancestry, performance metrics) for reproducibility. When choosing a score, check that its development and evaluation populations match the target.

例子Examples

  • 每個分數有 PGS 編號（如 PGS000001 格式）。Each score has an ID in the format PGS000001.
