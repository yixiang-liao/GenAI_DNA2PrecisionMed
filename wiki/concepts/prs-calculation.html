PRS 計算PRS Calculation

Concept ID: prs-calculation · Last Updated: 2026-11-13

初學者Beginner

計算方法很簡單：每個 SNP 的「權重 × 你有幾個」，全部加起來。PRS = Σ(βᵢ × Gᵢ)。

The calculation is simple: for each SNP, weight × how many copies you have, then add them up. PRS = Σ(βᵢ × Gᵢ).

進階Advanced

PRSⱼ = Σᵢ βᵢ · Gᵢⱼ。實務步驟：base GWAS 與 target 資料 QC → allele 對齊 → 處理 LD（clumping 或 LD-aware 收縮）→ 選擇 SNP 集合（P 值門檻或全基因體）→ 計算 → 在獨立樣本評估。分數常再標準化為 z-score 或百分位。

PRSⱼ = Σᵢ βᵢ · Gᵢⱼ. Practical steps: QC base GWAS and target data → harmonize alleles → handle LD (clumping or LD-aware shrinkage) → choose SNP set (P threshold or genome-wide) → compute → evaluate in an independent sample. Scores are often standardized to z-scores or percentiles.

例子Examples

  • （模擬）β = (0.12, −0.08)、G = (2, 1) → PRS = 0.24 − 0.08 = 0.16。(Simulated) β = (0.12, −0.08), G = (2, 1) → PRS = 0.24 − 0.08 = 0.16.
