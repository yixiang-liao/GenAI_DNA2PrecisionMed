RNA 定序RNA Sequencing (RNA-seq)

Concept ID: rna-seq · Last Updated: 2026-11-13

初學者Beginner

RNA-seq 把細胞裡的 RNA 抓出來定序，數一數每個基因的「影印本」有幾份，就知道哪些基因正在忙。

RNA-seq sequences the RNA in cells and counts the "photocopies" of each gene, revealing which genes are busy.

進階Advanced

流程：RNA 萃取 → 建庫（如 poly-A 選擇）→ 定序 → 品質控制 → 比對或 pseudo-alignment → 定量 → 差異表現／剪接／功能分析／eQTL。沒有一條流程適用所有研究；RNA-seq 也不是做完 WGS 才能做的下一步。

Workflow: RNA extraction → library prep (e.g. poly-A selection) → sequencing → QC → alignment or pseudo-alignment → quantification → differential expression / splicing / functional analysis / eQTL. No single pipeline fits all studies, and RNA-seq is not a step that requires WGS first.

例子Examples

  • 比較藥物處理前後的細胞，看哪些基因表現上升。Compare cells before and after drug treatment to see which genes go up.
