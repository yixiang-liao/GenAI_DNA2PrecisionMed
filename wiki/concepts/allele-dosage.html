對偶基因劑量Allele Dosage (G)

Concept ID: allele-dosage · Last Updated: 2026-11-13

初學者Beginner

Dosage 就是「數一數你有幾個 effect allele」：0 個、1 個或 2 個。

Dosage means counting your effect alleles: 0, 1 or 2.

進階Advanced

硬判定 dosage ∈ {0,1,2}；imputation 給出期望劑量 E[G] = P(het) + 2·P(hom-alt)，為 0–2 的小數。例如 P(het)=0.4、P(hom)=0.5 → dosage = 1.4。

Hard-called dosage ∈ {0,1,2}; imputation yields expected dosage E[G] = P(het) + 2·P(hom-alt), a decimal in 0–2. E.g. P(het)=0.4, P(hom)=0.5 → dosage 1.4.

例子Examples

  • effect allele = G：A/A → 0，A/G → 1，G/G → 2。Effect allele G: A/A → 0, A/G → 1, G/G → 2.

證據Evidence References

  • C-PRS-08 共識Consensus

    每人在一個位置有兩個 allele（父母各一），因此某 effect allele 的劑量（dosage）為 0、1 或 2；PRS 即加總這些 allele 並以效應量加權。Each person carries two alleles at a location (one from each parent), so the dosage of an effect allele is 0, 1 or 2; a PRS sums these alleles weighted by effect size.
