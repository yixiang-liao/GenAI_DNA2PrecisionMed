多基因風險分數Polygenic Risk Score · 3/8

對偶基因劑量Allele Dosage (G)

Concept ID: allele-dosage · Last Updated: 2026-11-13

初學者Beginner L1

Dosage 就是「數一數你有幾個 effect allele」：0 個、1 個或 2 個。

Dosage means counting your effect alleles: 0, 1 or 2.

進階Advanced L2

硬判定 dosage ∈ {0,1,2}；imputation 給出期望劑量 E[G] = P(heterozygous) + 2·P(homozygous for the effect allele)，為 0–2 的小數。例如 P(heterozygous)=0.4、P(effect allele 同型合子)=0.5 → dosage = 1.4。

Hard-called dosage ∈ {0,1,2}; imputation yields expected dosage E[G] = P(heterozygous) + 2·P(homozygous for the effect allele), a decimal in 0–2. E.g. P(heterozygous)=0.4, P(homozygous effect)=0.5 → dosage 1.4.

例子Examples

  • effect allele = G：A/A → 0，A/G → 1，G/G → 2。Effect allele G: A/A → 0, A/G → 1, G/G → 2.
