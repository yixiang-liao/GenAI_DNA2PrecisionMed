參考基因體Reference Genome

Concept ID: reference-genome · Last Updated: 2026-11-13

初學者Beginner

參考基因體是一本「標準版」說明書。我們把每個人讀到的片段對照它，就能找出哪裡不一樣。

A reference genome is a "standard edition" of the book. We compare each person's reads against it to find differences.

進階Advanced

參考基因體是比對與變異座標的基準。T2T-CHM13（2022）補上舊參考缺少的約 8%，包括著絲粒與近端著絲粒染色體短臂。參考只是座標系統，不代表「正常」或「理想」的人類序列。

The reference genome is the coordinate system for alignment and variant calls. T2T-CHM13 (2022) filled the ~8% missing from earlier references, including centromeres and acrocentric short arms. A reference is a coordinate system, not a "normal" human sequence.

例子Examples

  • （示意）變異 chr7:1,234,567 G>A 的座標依賴所用的參考版本。(Illustrative) The coordinate of a variant like chr7:1,234,567 G>A depends on the reference build used.
