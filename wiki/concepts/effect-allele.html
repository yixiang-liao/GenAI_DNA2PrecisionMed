效應對偶基因Effect Allele

Concept ID: effect-allele · Last Updated: 2026-11-13

初學者Beginner

GWAS 會指定一個版本作為「被計算的那個」，叫 effect allele。效應量描述的就是每多帶一個 effect allele 的影響。

A GWAS designates one version as the counted one — the effect allele. The effect size describes the impact of each extra copy of it.

進階Advanced

Effect allele 不一定是 alternate allele 或少見 allele，也不一定增加風險（β 可為負）。合併 GWAS 與目標 genotype 時必須對齊 allele（含 strand flip 與 palindromic SNP 如 A/T、C/G），否則權重符號會錯。

The effect allele is not necessarily the alternate or minor allele, nor necessarily risk-increasing (β can be negative). When combining GWAS with target genotypes, alleles must be harmonized (strand flips, palindromic A/T, C/G SNPs) or weights get the wrong sign.

例子Examples

  • GWAS：effect allele = G、β = +0.1；某人為 A/G → dosage = 1。GWAS: effect allele G, β = +0.1; a person with A/G → dosage 1.
